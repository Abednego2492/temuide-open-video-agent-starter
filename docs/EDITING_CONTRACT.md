# Editing contract

The asset manifest, edit decision list, dynamic style contract and scene plan should be saved per project before heavy rendering.

For each scene capture: source asset ID; source in/out; timeline start/duration in integer frames; semantic goal; focal object; layout x/y/w/h; font metrics; color tokens; motion entrance/hold/exit; B-roll justification; audio cues; ending transition.

Use traceable input evidence for all claims about the reference. Never use silence-only cuts when speech context is important. Do not overwrite source assets. Any missing capability is marked unavailable rather than silently substituted with an invented result.
