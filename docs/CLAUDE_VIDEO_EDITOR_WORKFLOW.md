# Claude video editor workflow (v0.2.0)

This is the workflow used to edit two real talking-head / animated videos end to end inside a Claude chat, operated from a phone. It works the same in Claude Code or any agent that has a Linux shell, Node and Python.

The short version: **turn on network access, transcribe before you cut, look at your own renders, and never ship a voice line you have not transcribed back.**

## 0. Give the agent a working sandbox

On claude.ai (web or mobile app), the agent can only install packages and download models if network access for files is on:

- Settings → Capabilities → *Use the internet while making files* = ON (standard download sites is enough).
- npm, PyPI and GitHub (including `media.githubusercontent.com` and release assets) are reachable. HuggingFace and Google Storage usually are not, so download models from GitHub releases.
- If you use an external API (for example ElevenLabs), add its domain (`api.elevenlabs.io`) to the allowed domains.

Without network the agent falls back to guessing captions and the result looks generic. That was the single biggest quality jump.

## 1. Toolchain that worked

| Job | Tool | Source |
|---|---|---|
| Speech-to-text | `sherpa-onnx` + `sherpa-onnx-whisper-small` | PyPI + k2-fsa GitHub release |
| Word timing | Whisper segment timestamps + RMS speech frames (10 ms), words weighted by syllable count | own script |
| Face box | OpenCV YuNet `face_detection_yunet_2023mar.onnx` | opencv_zoo via media.githubusercontent.com |
| Person cutout (text behind head) | `rembg` `u2net_human_seg` | GitHub release |
| Composition / render | Remotion 4.0.539, fonts via `@fontsource/*` | npm |
| Browser for render | local Chromium (Playwright build) with `chromeMode: 'chrome-for-testing'` | preinstalled |
| SFX | synthesised with numpy (click, type, whoosh, pop, tick, ding, freeze, buzz, slam, pencil, steps) | own script |
| Voiceover | ElevenLabs `eleven_v4` + voice clone | see [VOICEOVER.md](VOICEOVER.md) |

Use `@fontsource/*` instead of Google Fonts URLs; font CDNs are often blocked in sandboxes.

## 2. Edit order

1. **Probe and transcribe every clip.** Correct the transcript with a glossary (brand names, "Claude" vs "cloud").
2. **Cut list in seconds per source file.** Keep complete phrases only. Write it down; it is the EDL.
3. **Word frames.** Align each word to the speech that is actually audible, not to the segment start.
4. **Face + safe zones.** Run YuNet per frame. Place captions in negative space using a motion mask plus a skin mask (extend upward for hair). Fall back to a smaller font, then to two lines.
5. **Pick a style with the user before building.** Offer 2–3 named concepts (see `examples/`). Do not ship the kit's default theme as "the edit".
6. **Build the Remotion composition** from data files (`data.ts` / JSON) generated by the scripts above.
7. **Look at stills before a full render.** `node scripts/stills.mjs <frames…>` renders frames at 0.4 scale; check a contact sheet of hook, every scene, and the ending.
8. **Render in chunks** (`scripts/render_chunks.sh`). Chat sandboxes can restart mid-render; chunks survive that.
9. **Master audio** to −14 LUFS integrated, true peak ≤ −1 dBTP.
10. **Critic pass on the real MP4**: loudness, black frames, A/V sync, contact sheet at phone scale.

## 3. Render in chunks

A 2-minute 1080×1920 video took ~15 minutes on 2 CPUs. A single long render was killed when the chat environment restarted. The fix:

```bash
COMP=MyComp TOTAL=3609 CHUNK=1350 bash scripts/render_chunks.sh
```

It renders muted video parts, renders the audio once as WAV, concatenates the parts losslessly, masters the audio and muxes `output/final.mp4`. Parts that already exist are skipped, so re-running resumes.

If you change something that only affects later frames (for example one voice line late in the video), delete only the parts after that point.

## 4. Gotchas we hit

- **A/V sync measurement:** measure from fully decoded audio. Seeking AAC with `-ss` produces fake 20–50 ms offsets.
- **Captions colliding with the head:** solved by the motion + skin mask, not by moving captions to a fixed corner.
- **Neighbouring scenes bleeding into frame** on a camera journey: space stations ≥ 1050 px apart and hide text outside its own scene.
- **Whisper in Indonesian mode translates English speech** ("Back to my old school" became "Kembali ke sekolahku"). When a line mixes languages, re-check the English part with `language="en"` before assuming the audio is wrong.
- **TypeScript use-before-declare** when timing constants are derived from data: compute the timeline right after the data, before the camera code.

## 5. What the agent must still not claim

A successful render is not proof of quality. The agent should send stills or a preview, ask for timestamped feedback, and keep a short handoff note (cut list, transcript, style decisions) so the next video does not start from zero.
